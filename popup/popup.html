Paramètres de traduction LingoSlide

👋 Bienvenue sur LingoSlide !

Pour commencer à traduire vos conversations gaming, vous avez besoin d'une clé API Google Gemini.

  1. Rendez-vous sur Google AI Studio.
  2. Connectez-vous avec votre compte Google.
  3. Cliquez sur "Create API Key" (Créer une clé API).
  4. Copiez la clé générée et collez-la ci-dessous.
Votre clé est stockée localement et n'est jamais envoyée à nos serveurs.
Le modèle indiqué sera utilisé en priorité. En cas d'erreur, un fallback automatique sera tenté.
Si activé, le message traduit sera envoyé automatiquement dans le tchat après traduction.
